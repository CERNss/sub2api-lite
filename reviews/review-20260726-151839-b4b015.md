## High

### 1. Toolchain versions are inconsistent across Docker, Go module, and docs

- File path and line: `Dockerfile:10`, `backend/Dockerfile:1`, `backend/go.mod:3`, `README.md:5`, `DEV_GUIDE.md:56`
- Severity: high
- Category: Holistic
- Description: Docker build images pin Go `1.26.4`, while `backend/go.mod` requires `go 1.26.5`. The README and developer guide still reference Go `1.25.7`. This makes local setup, CI, and container builds disagree on the supported compiler version.
- Suggested fix: update Dockerfiles and docs to match `backend/go.mod`, or derive the image tag from one canonical version source. Add CI coverage for the default Docker build path.

### 2. Fresh installs may not default to backend/admin-only mode

- File path and line: `backend/internal/service/setting_service.go:2257`, `backend/internal/service/setting_service.go:2651`
- Severity: high
- Category: Holistic
- Description: The lite branch intent says fresh installs should default to backend/admin-only mode, but a missing `backend_mode_enabled` setting appears to read as `false`. The seeding path, `InitializeDefaultSettings`, appears uncalled. A fresh deployment may therefore expose behavior outside the intended lite defaults.
- Suggested fix: choose a single startup, migration, or default-value mechanism for this setting and add a fresh-install regression test.

### 3. Removed payment providers remain as direct Go dependencies

- File path and line: `backend/go.mod:32`
- Severity: high
- Category: Diff / Holistic
- Description: Removed payment/provider functionality still leaves direct dependencies on `shopspring/decimal`, Alipay, Stripe, and WeChat Pay SDKs. The active lite-scope spec requires those SDKs not to remain declared, and the diff review found no Go imports for them. This keeps unnecessary supply-chain and audit surface after deleting the payment code.
- Suggested fix: run `go mod tidy`, commit the resulting `go.mod` and `go.sum` removals, and add a CI assertion or OpenSpec boundary check to block these modules from reappearing.
